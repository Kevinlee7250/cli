# 전체 시스템 점검 · AdSense 승인 가능성 진단

> 2026-08-19 · 대상 3개 블로그 · 브랜치 `claude/blog-automation-system-KAbtE`

---

## 1. 핵심 결론

**현재 상태로는 승인 가능성 5~10%입니다. 신청 중이시라면 거절될 것으로 봅니다.**

이유는 발행량이나 글 품질이 아닙니다. **이미지 저작권**입니다.

| 지표 | 값 |
|---|---:|
| 사용된 이미지 총계 | 835개 |
| 저작권 안전 출처 (Pixabay·Wikimedia·Unsplash) | **245개 (29%)** |
| **`imgnews.naver.net` (언론사 뉴스 사진)** | **299개 (36%)** |
| 기타 무단 출처 (다음·네이버블로그·핀터레스트·나무위키·커뮤니티) | 291개 (35%) |

**전체 이미지의 71%가 타인의 저작물을 무단으로 가져다 쓰고 있습니다.**

한국경제·동아일보 등 언론사 사진, 나무위키, 뽐뿌·보배드림·인스티즈 커뮤니티 게시물, 핀터레스트, 유튜브 썸네일까지 포함돼 있습니다.

이것은 AdSense 프로그램 정책 위반(저작권)에 직접 해당하며, 승인 거절 사유일 뿐 아니라 **승인 후 발견되면 계정 정지 사유**입니다. 언론사가 인지하면 별도의 법적 문제로도 번질 수 있습니다.

**최근에도 계속되고 있습니다** — 최근 사용 이미지 200개 중 안전한 것은 20%뿐입니다.

### 2-3. 이미지 문제가 왜 생겼나

`image_fetcher.py`의 검색 순서가 원인입니다.

```
1순위 Pixabay      (저작권 무료)      ← 한국어 키워드에 결과 없음
2순위 네이버 이미지  (저작권 있는 웹 이미지) ← 여기로 떨어짐
3순위 DuckDuckGo    (저작권 있는 웹 이미지)
4순위 Wikimedia     (저작권 무료)
```

Pixabay는 영어 기반이라 "종부세 개편", "가계부채 2000조" 같은 한국어 시사 키워드에서는 결과가 없습니다. 그래서 2순위인 네이버 이미지 검색으로 넘어가고, 네이버는 **뉴스 기사 사진을 그대로 반환**합니다.

코드에 출처 표기 기능(`_attribution_text`)은 있지만, 표기 문구가 `"이미지 출처: 네이버 이미지 검색"`입니다. **이건 라이선스가 아닙니다.** 출처를 적는다고 타인의 저작물을 쓸 권리가 생기지 않습니다.

추가 문제: 이미지가 블로그에 업로드되지 않고 **원본 서버에서 핫링크**되고 있습니다(`blogger_img_proxy`). 원 저작권자가 파일을 옮기면 글의 이미지가 전부 깨집니다.

### 2-4. 색인 문제 (어제 조치했으나 회복 전)

| 지표 | 값 |
|---|---|
| 총 페이지 | 478 |
| 색인 완료 | 0 |
| GSC 30일 노출 | 3회 (blog2), 0회 (blog3), 데이터 없음 (blog1) |

어제 발행량을 9.2 → 1건/일로 줄였으나, 구글의 신뢰 회복에는 수 주가 걸립니다. **색인이 안 된 사이트는 AdSense 심사에서 "가치 있는 콘텐츠 부족"으로 판정됩니다.**

### 2-5. 기존 발행글의 주제 중복은 남아 있음

설정(`blogs.json`)은 분리했지만 **이미 발행된 글은 그대로**입니다.

| 블로그 | travel 카테고리 글 |
|---|---:|
| HOGU What? | 62건 |
| HOGU 여행·스포츠·연예 | 61건 |

두 블로그가 여행 글 60여 건씩을 각각 갖고 있어, 여전히 "같은 운영자의 중복 사이트"로 보입니다.

### 2-6. 그 외 발견 사항

| 항목 | 내용 | 심각도 |
|---|---|---|
| 대기 글 160건 | `pending_posts.json`에 발행 대기 상태로 적체. 자동 발행되지는 않음 | 낮음 |
| `collect-keywords.yml` 하루 8회 | 키워드 수집만 하므로 발행량과 무관 | 낮음 |

## 3. 실행 전략

### 3-1. 즉시 (신청 중이라면 지금 바로)

| # | 조치 | 방법 | 효과 |
|---|---|---|---|
| **1** | **이미지 검색 순서 변경** | 네이버·DDG를 검색 경로에서 **제거**. Pixabay → Wikimedia → 자체 생성 썸네일 순으로 | 신규 글 저작권 위험 제거 |
| **2** | **기존 무단 이미지 590장 교체** | 자동 교체 스크립트 필요 (아래 4-1) | 거절 사유 해소 |
| **3** | **Pixabay 영어 쿼리 강화** | 한국어 → 영어 매핑 확대 (이미 `_KO_EN` 존재) | Pixabay 적중률 상승 |
| **4** | **자체 썸네일 생성 우선** | `generate_title_thumbnail()` 이미 존재 — 이걸 2순위로 | 100% 안전 |

> ⚠️ **신청을 취소하거나 대기시키는 것을 권합니다.** 지금 심사가 진행되면 거절되고, 거절 이력이 쌓이면 재승인이 더 어려워집니다.

### 3-2. 단기 (2~4주)

| 조치 | 내용 |
|---|---|
| 블로그 1개로 집중 | 3개 동시 승인 시도 대신 **금융NEWS 하나만** 먼저 승인받기 |
| 나머지 2개 임시 비공개 | 중복 사이트 신호 제거. 승인 후 순차 공개 |
| 색인 회복 대기 | 발행 1건/일 유지하며 GSC 색인률 30% 도달까지 |
| 기존 travel 글 정리 | blog2의 여행 글 61건을 blog1로 이전 또는 비공개 |

### 3-3. 중기 (1~3개월)

| 조치 | 내용 |
|---|---|
| 외부 링크 확보 | 현재 사실상 0. 도메인 권위의 근본 |
| 커스텀 도메인 | blog2·blog3도 blogspot 서브도메인 탈피 |
| AdSense 재신청 | 색인률 30%+ / 이미지 100% 정화 후 |

## 5. 예상 결과

| 시나리오 | 조치 | 승인 확률 | 시점 |
|---|---|---:|---|
| **현재 그대로** | 없음 | **5~10%** | — |
| **이미지만 정화** | 1~3번 | 30~40% | 4주 후 |
| **이미지 + 단일 블로그 집중** | 1~4번 | 55~65% | 6주 후 |
| **전체 실행** | 1~6번 | **70~80%** | 8~12주 후 |

> 확률은 AdSense 심사 실무 관행에 근거한 추정이며 구글의 공식 기준은 비공개입니다.

**핵심**: 이미지 저작권을 해결하지 않으면 다른 무엇을 해도 승인되지 않습니다. 반대로 이미지만 해결하면 나머지 조건은 이미 상당 부분 갖춰져 있습니다.

## 6. 추가 개선 아이디어

1. **AI 이미지 생성 도입** — 저작권 걱정이 없고 글 내용에 정확히 맞는 이미지를 만들 수 있습니다. 현재 `_SOURCE_LABELS`에 `ai_generated` 항목이 이미 준비돼 있습니다.
2. **이미지 소스 화이트리스트 강제** — 코드에 허용 도메인 목록을 두고, 목록 밖 도메인은 삽입 자체를 차단하는 가드레일.
3. **저작권 감사 워크플로** — 발행된 글의 이미지 도메인을 주기적으로 검사해 위반 건을 대시보드에 표시.
4. **대시보드 최상단을 "저작권 안전율"로** — 현재는 추정 수익이 최상단이라 실제 위험이 가려집니다.
5. **AdSense 신청 자동 차단** — 저작권 안전율 100% 미만이면 신청을 막는 체크.
6. **텍스트 중심 시각자료로 전환** — 표·차트·인포그래픽을 직접 생성하면 저작권 문제가 없으면서 E-E-A-T 신호는 오히려 강해집니다.
