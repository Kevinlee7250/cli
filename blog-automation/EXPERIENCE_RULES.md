# 경험 주장 규칙 (AIOPS-59, 2026-11-26)

원칙: **글쓴이가 하지 않은 경험·방문·확인을 했다고 쓰지 않는다.** 걸리면 발행하지 않고 검토 대기(품질 보류)로 둔다.

| 구분 | 예 | 판정 |
|---|---|---|
| 1인칭 + 과거 경험 | "저도 고3 때 알바해 봤는데", "제가 겪었던" | 차단 |
| 직접 + 완료형 | "직접 세 곳을 돌며 확인한", "직접 해본 후기" | 차단 |
| 경험 근거 문구 | "개인적인 경험을 바탕으로", "~한 기억이 있습니다" | 차단 |
| 공개 정보 기반 | "공식 발표 기준으로는", "이용자 후기를 종합하면" | 허용 |
| 조사 행위 | "자료를 정리했습니다", "직접 대조해본 결과" | 허용 |
| 권유·희망 | "직접 확인한 뒤 신청하세요", "직접 경험해보고 싶다면" | 허용 |
| 의견 | "저라면 ~하겠습니다", "제 생각에는" | 허용 |
| 남의 말 인용(따옴표) | 배우의 "저는 힘들었어요" | 허용 |
| 실제 경험 자료 | `author_profile.json`에 있는 주제 + 자료에 있는 숫자만 | 허용 |

## 코드의 어디에 있나

| 단계 | 파일 | 역할 |
|---|---|---|
| 시리즈 기획 | `series_planner.py` | 경험 주장 금지 문구 |
| 본문 생성 | `content_generator.py` `_experience_style_block` | 조사·분석형 지시 |
| 사실성 검사 | `content_generator.py` `_fact_check_content` | LLM 보조 검사(앞 3,500자, 오류 시 통과) |
| AdSense 자동 수정 | `adsense_validator.py` `fix_adsense_issues` | 새 경험·수치 추가 금지 |
| 최종 편집 | `final_editor.py` | 경험 주장 제목 교체 거부 |
| **발행 전 게이트** | `experience_gate.py` — `main.py`, `blogger_uploader.upload_post` | 규칙 검사, 검사 오류도 보류, 해제 스위치 없음 |

## 알려진 한계
- 정규식 검사라 주어·'직접'이 없는 경험담("가 보니 좋았습니다")은 놓칠 수 있다.
- "저는 … 발표했던 기준이 낫다고 봅니다"처럼 과거형이 섞인 의견은 걸릴 수 있다.
- 실제 경험 자료가 있는 주제는 단어 하나만 겹쳐도 허용 범위가 된다(숫자 없는 지어낸 문장은 통과).
- 이미 발행된 글을 고치는 경로(update API)는 이 게이트를 거치지 않는다.
