# 색인 병목 진단 보고서

> 작성일 2026-08-18 · 브랜치 `claude/blog-automation-system-KAbtE`
> 대상: 3개 블로그(HOGU What? / HOGU 여행·스포츠·연예 / 금융NEWS)

---

## 1. 핵심 결론

**색인이 안 되는 원인은 인증·사이트맵·기술 설정이 아닙니다. 발행 패턴 자체입니다.**

3개 블로그가 2주 간격으로 개설되어 각각 하루 3~4건씩 총 **478건**을 쏟아냈고,
그 결과 30일간 검색 노출이 **총 3회**입니다. 이 조합은 구글 스팸 정책의
**대규모 콘텐츠 남용(scaled content abuse)** 정의와 문구 단위로 일치합니다.

> "여러 사이트를 만들어 콘텐츠의 대규모 생성 특성을 감추는 행위"
> — Google Search 스팸 정책, 대규모 콘텐츠 남용 항목

**따라서 지금 상태에서 글을 더 많이 쓸수록 상황은 악화됩니다.**
AdSense 승인의 선결 조건은 색인이고, 색인의 선결 조건은 **발행량 감축**입니다.

### 2-3. 기술 설정은 정상

오히려 기술 쪽은 문제가 없다는 점이 진단을 확정시킵니다.

| 점검 항목 | 상태 | 근거 |
|---|---|---|
| 사이트맵 | ✅ 정상 | 3개 전부 접근 가능, 478 URL 정상 등재 |
| OAuth 인증 | ✅ 정상 | `auth_health.json` → `ok=true` (실제 토큰 교환 성공) |
| GSC 읽기 권한 | ✅ 정상 | `gsc.json` 08-18 정상 수집 |
| ads.txt | ✅ 정상 | 3개 블로그 전부 통과 |
| 글자수 | ✅ 양호 | 중앙값 3,274자 (2,500자 미만 20건뿐) |
| 구조화 데이터 | ✅ 적용 | Article + FAQPage JSON-LD |
| 내부 링크 | ✅ 적용 | 포스트당 최대 5개 자동 삽입 |
| 키워드 중복 | ✅ 경미 | 234종 중 중복 7종 |

**즉, 고칠 기술 항목이 남아 있지 않습니다.** 남은 변수는 발행 패턴뿐입니다.

### 2-4. 왜 "Discovered - currently not indexed"인가

이 상태값은 **구글이 URL을 알고 있지만 크롤을 미룬 것**입니다.
사이트맵 제출이 실패했다면 나올 수 없는 값이므로, 후보였던
"사이트맵 쓰기 권한 부족"은 원인이 아닙니다.

크롤 우선순위가 밀리는 표준 원인과 대조:

| 표준 원인 | 해당 여부 |
|---|---|
| 서버 응답 속도 | ❌ (Blogger 인프라) |
| 내부 링크 부족 | ❌ (자동 삽입 중) |
| robots.txt 차단 | ❌ |
| 중복 URL·프로토콜 혼재 | ❌ |
| **콘텐츠 품질·중복 신호 → 크롤 예산 축소** | ✅ **유일하게 해당** |

### 2-5. 가중 요인 — blog1·blog2 주제 중복

`blogs.json` 기준 두 블로그의 `topics`가 **6개 겹칩니다**
(국내여행·해외여행·드라마·영화·연예·K-POP).

같은 운영자의 두 사이트가 동일 주제를 다루는 구조는 스팸 정책의
"여러 사이트로 대규모 생성을 감추는 행위" 판정에 직접 기여합니다.
실제로 발행 카테고리도 `travel` 120건으로 최다입니다.

## 3. 실행 전략

### 전략 방향: **양 → 질 전환 + 사이트 통합**

현재 시스템은 "많이 쓰면 수익이 난다"는 전제로 설계되어 있으나,
실측 데이터는 그 전제가 이 단계에서 역효과임을 보여줍니다.

### 3-1. 즉시 (0~3일) — 출혈 중단

| 조치 | 방법 | 근거 |
|---|---|---|
| **발행량 90% 감축** | `POSTS_PER_RUN` 3 → 1, 스케줄 2회/일 → 1회/일 | 9.2건/일 → **1건/일** |
| **blog1·blog2 주제 분리** | `blogs.json`: blog1=여행 전담, blog2=스포츠·연예 전담 | 중복 신호 제거 |
| **색인 검사 재실행** | Actions → `gsc-indexing` 수동 실행 | 현 데이터는 표본 편향(1~2일 글만 검사) |
| blog1 GSC 속성 수정 | 커스텀 도메인 → `sc-domain:` 형식 확인 | 데이터 자체가 안 잡힘 |

> ⚠️ **발행 중단이 아니라 감축입니다.** 완전 중단은 사이트 방치 신호가 됩니다.

### 3-2. 단기 (1~4주) — 품질 신호 회복

| 조치 | 대상 | 방법 |
|---|---|---|
| 저품질 글 정리 | 2,500자 미만 20건 | 보강 또는 비공개 전환 |
| FAQ 보강 | blog3 58건 (대부분 07-20 이전 레거시) | 대시보드 → AdSense 감사 → FAQ·출처 보강 |
| 출처 보강 | blog3 10건 | 동일 도구 |
| 대표 글 육성 | 블로그당 5~10건 | 5,000자+ 깊이 있는 글로 수동 재작성 |
| 색인 요청 | GSC 웹 UI, 속성당 하루 ~10건 | `index_priority.py` 우선순위 순 |

### 3-3. 중기 (1~3개월) — 권위 확보

| 조치 | 설명 |
|---|---|
| 외부 링크 확보 | 현재 사실상 0. 네이버 카페·커뮤니티·관련 블로그 언급 |
| 사이트 통합 검토 | 3개 → 2개 또는 1개. 도메인 권위 분산이 최대 손실 요인 |
| 커스텀 도메인 | blogspot 서브도메인은 권위 축적 불리 (blog1은 이미 적용) |
| AdSense 재신청 | **색인률 30% 이상 확보 후** 신청 |

## 5. 예상 결과

| 시점 | 지표 | 현재 | 목표 |
|---|---|---:|---:|
| 4주 | 색인률 | ~0% | 15~30% |
| 4주 | GSC 노출/월 | 3 | 300+ |
| 8주 | 색인률 | — | 40~60% |
| 12주 | AdSense 승인 가능성 | 매우 낮음 | 중간 |

**전제**: 발행량 감축이 실행될 경우. 현 발행 속도를 유지하면
색인률은 개선되지 않을 가능성이 높습니다.

### 수익 추정치 정정

현재 대시보드의 추정 수익 189,800원은 **가정 CTR 2.5% + CPC $1~3** 기반이며,
함의 RPM이 $38.61입니다. 한국어 블로그 실제 RPM은 **$0.5~3**로,
자릿수 단위 과대 추정입니다. 노출이 30일간 3회인 현 상태의 실제 수익은
**사실상 0원**입니다. 승인 전까지 이 수치를 의사결정 근거로 쓰지 마세요.

## 6. 추가 개선 아이디어

1. **`POSTS_PER_RUN` 상한 하드코딩** — 색인률이 일정 수준에 도달하기 전까지
   설정값과 무관하게 1일 1건으로 제한하는 가드레일.
2. **색인률 연동 발행량 자동 조절** — `index_status.json`의 색인률을 읽어
   30% 미만이면 발행량을 자동 감축하는 피드백 루프. 현재는 색인 상태와
   발행량이 완전히 분리되어 있습니다.
3. **품질 게이트 강화** — 4,500자 미만 자동 거부는 있으나, 독창성 검사
   (기존 글과의 유사도)가 없습니다. 3개 블로그 교차 중복 검사 추가.
4. **AdSense 신청 자동 차단** — 색인률 미달 시 신청을 막는 체크.
   반려 이력이 쌓이면 재승인이 더 어려워집니다.
5. **대시보드에 "색인률" 최상단 배치** — 현재 추정 수익이 최상단이라
   실제 병목이 가려집니다.
